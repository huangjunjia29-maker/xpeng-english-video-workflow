# English Voiceover and B-roll Mode

Use this mode only when the user requests narration, talking-head-style audio, or B-roll storytelling.

## Story and Voice

Write natural spoken English with a human reaction, not a news bulletin. Keep each narration unique across a batch. Use the same factual backbone when needed, but vary the opening, phrasing, humor, and conclusion.

Generate or obtain word-boundary timing from the actual approved voice. Do not estimate timing from character count. Fit audio conservatively; avoid obvious speed stretching, pitch artifacts, clipping, silence tails, or abrupt loudness changes.

## Audio and Visual Mapping

Map each narration segment to one authorized material class. Robot narration uses robot footage, sales narration uses sales material, and VLA narration uses VLA footage. Do not let the previous visual category spill into a new spoken section.

Remove original music when the user requests voiceover-only audio. Preserve original ambience only when explicitly desired and mix it below narration. Do not add watermarks.

## Batch Rules

Approve one complete sample before batch production when the format is new. Every batch video must have distinct narration and audio. Check audio fingerprints or scripts for accidental reuse.

Use [title-and-subtitle.md](title-and-subtitle.md) for subtitle grouping, baseline, and title overlay rules.
